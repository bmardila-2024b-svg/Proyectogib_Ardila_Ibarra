# Los 3 Chiflados del Software 🧠💻

## 📌 Descripción
Este es un sitio web tipo **hoja de vida y portafolio** para *Los 3 Chiflados del Software*.  
Incluye secciones para presentar el **equipo**, los **servicios** ofrecidos y la **información de contacto**, con una interfaz atractiva usando **Bootstrap 5** y CSS personalizado (fondo con imagen + capa oscura para legibilidad).

## ✅ Características
- 🌈 Estilo visual con imagen de fondo (`imagenes/fondo.jpg`)
- 🧱 Tarjetas con diseño para mostrar a cada integrante del equipo
- 🧭 Barra de navegación con enlaces internos:
  - `#equipo`
  - `#servicios`
  - `#contacto`
- 📋 Sección de **Servicios** con íconos
- 📞 Sección de **Contacto** con datos y redes
- 🦶 Footer con copyright
